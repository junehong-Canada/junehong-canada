# Mobile Applications Portfolio

Welcome to the marketing repository for our suite of smart mobile applications. This collection features tools designed to enhance productivity and organization in your daily life.

## Projects

### 1. [SmartShopper](README%20-%20SmartShopper.md)
**Intelligent Shopping List App**

SmartShopper is designed to make grocery shopping faster, smarter, and more organized. It helps you save time with intuitive features like category grouping and quick item entry.

*   **Key Features:** Simple interface, category grouping, multiple lists, and smart suggestions.
*   [View full documentation](README%20-%20SmartShopper.md)

### 2. [SmartMembership](README%20-%20SmartMembership.md)
**Digital Loyalty Card Wallet**

SmartMembership is a lightweight iOS application that digitizes your physical membership and loyalty cards. It focuses on privacy and performance using native frameworks.

*   **Key Features:** Universal barcode scanner (QR, EAN-13, UPC-A), high-quality barcode rendering, and local processing.
*   [View full documentation](README%20-%20SmartMembership.md)
